# S-230. Documentation: the editor of Notification rule sequences, custom rules and the Organization's default rules

## Scope

**IN**

- C-41.FR-11: the editor, its checks and warnings, the preview, what custom rules mean for later changes and how to
  return, and the editor of the Organization's default rules, with screenshots.
- The documentation link of the editor, and the revision marker on C-31.FR-5 that C-41.FR-11 asks for.

**OUT**

- The editor itself: S-228, S-229. The page's earlier sections — the states, the switch, the steps of a chain, Mentions
  and Account links, calls in rules — written by S-161, which this story extends and does not rewrite.
- The Terraform resource of the Organization's default rules and its guide: C-33.

## Contracts

- **Pages**: `docs/concepts/notification-rules.md` — the new section `## The editor of sequences` (anchor `#editor`)
  after "Custom rules", and the sentences of "In the web UI" that today say custom rules are set through the API or by
  an Admin, which now say that the person may also have set them; `docs/configure/organization.md` — in the part about
  Alert handling, the editor of the Organization's default rules. The navigation in `mkdocs.yml` is unchanged: the pages
  exist. The Russian pages, if the site has them, follow the existing practice of the docs.
- **Documentation links** (`web/src/lib/docs-links.json`): `field.notification_rules_editor` →
  `concepts/notification-rules.md#editor`; `notification-rules-editor.tsx` shows a "Learn more" through the existing
  `DocsLink`, with its test; `docslinkcheck` checks the entry against the built site.
- **PRD**: `design/prd/l2/C-31-notification-rules.md`, FR-5, a marker `_Revised for L2 (date):_` in the form the other
  revisions of L2 use, as C-41.FR-11 asks; no other line of the capability file changes.
- **Screenshots** (`web/e2e/screenshots/notification-rules.spec.ts`, a new spec): the editor with the important rule
  "Mention, wait 3 minutes, call" and its preview in the profile, and the Organization's editor on Alert handling, in
  `docs/assets/screenshots/concepts/notification-rules/`; light theme as every documentation screenshot is (C-39.FR-7);
  generated, never listed.
- **Examples**: generic only (the Notification gateway "Phone gateway", `+7 900 *** ** 00` as the masked contact,
  `example.org`).
- **Settings cited**: `notification_rule.limits`.

## Steps

1. Write the section, the Organization's part and the changed sentences. Check: `make docs-serve`.
2. Add the link entry and the "Learn more", the marker in C-31 and the screenshot spec. Check:
   `make docs-screenshots GUIDES=notification-rules`.
3. Check the site and the component. Check: `make docs-check`, `make ci`.
